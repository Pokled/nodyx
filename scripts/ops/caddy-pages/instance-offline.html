Nodyx · Instance hors-ligne

Cette instance est temporairement injoignable

…

Le tunnel Nodyx est enregistré, mais le serveur de la communauté ne répond pas pour le moment.

  • Le plus fréquent : votre réseau bloque les connexions sortantes vers le port 7443. C'est le cas de beaucoup de réseaux d'entreprise, d'université ou d'institut, qui n'autorisent que le 443. Votre instance fonctionne, mais son tunnel n'arrive pas jusqu'à nous.
  • L'installation est peut-être encore en cours (la compilation prend quelques minutes).
  • Le serveur de la communauté a redémarré, ou le client relais est arrêté.

Vérifier en une commande, sur votre serveur :

nc -zv relay.nodyx.org 7443     # doit répondre « succeeded »
nc -zv relay6.nodyx.org 7443    # la même chose, en IPv6
systemctl status nodyx-relay    # le client doit être « active »
journalctl -u nodyx-relay -n 20 # les tentatives de reconnexion

Si nc échoue alors que votre serveur accède bien à Internet, c'est votre pare-feu sortant. Autorisez le port 7443 en sortie, ou contactez l'administrateur du réseau. Vous n'avez aucun port à ouvrir en entrée, Nodyx ne le demande jamais.

Si la première commande échoue mais que la seconde répond, votre réseau laisse passer l'IPv6 : basculez le client sur relay6.nodyx.org:7443, c'est le même relais par une autre route.

Guide complet de déblocage : comment lire le résultat de chaque commande, et un message prêt à envoyer à votre administrateur réseau.
